# content-registry — docs

One declarative map of every content type (table, slug col, translatable fields, feed-kind, icon, section, searchable) that feed / board / seo / mcp / search / compose all read — replacing five duplicated hardcoded maps.

- **Source:** https://github.com/fadymondy/content-registry
- **Reference app:** https://fadymondy.com

## Install

```bash
togo install fadymondy/content-registry
```

The plugin self-registers on blank-import (no manual wiring). See the top-level
README for usage. This plugin was extracted from the fadymondy.com togo app as
part of turning that site into a reusable plugin suite.
